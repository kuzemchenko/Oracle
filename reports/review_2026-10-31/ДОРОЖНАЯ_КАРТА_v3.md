# ДОРОЖНАЯ КАРТА «Оракул v3» — от честного нуля к работающему партнёру

**Дата: 31.10.2026. Статус: предложена владельцу (этапы V0–V3 не требуют подписей и стартуют сразу;
V4–V5 ждут пакетов подписей — см. §5).**

Как составлена: аудит пятью перспективами + критик (reports/review_2026-10-31/АНАЛИЗ_что_получилось.md),
затем три независимых проекта редизайна («продукт первый» / «доказательство первое» / «процесс первый»),
две судейские оценки (судья-«владелец» выбрал продукт, судья-«инженер» — процесс) и синтез. Скелет —
продукт; хребет — машинный процесс, который не умеет бросать; совесть — доказательная программа.

Три слагаемых диагноза, на которые карта отвечает:
1. **Мотор жив, доставка мертва.** ~17 печатей в день, живой конвейер — но 124 дня без единой
   «денежной» идеи, потому что ворота денег стоят на пути показа, а подача — не та, что согласована.
2. **Три пивота брошены по процессу, не по содержанию.** Лечится не дисциплиной, а машинным
   состоянием дорожной карты со стоп-правилами.
3. **Edge в зоне «тикер × 5 дней» не найден на 733 связях** — охота сдвигается туда, где
   предсказуемость доказана (события, 3–13 недель), а проверенное умение системы (калибровка
   на N=1506) становится товаром.

## 2. Этапы V0–V7

Правило всех этапов (новый инвариант процесса): **этап не считается закрытым, пока его результат
не виден владельцу в Telegram** — гейт обязан содержать ссылку на реальный пуш.

### V0. «Идея дня» в бой + честный ноль — неделя 1, подписей не требует (~3 сессии)
Реализовать согласованный 15.07 формат поверх УЖЕ живого (сервер в июле сам сделал пол-дела:
исследовательский суд отделён от денежного — тег fix-A1, подача «Топ-3» ранжирует идеи):
- одно утреннее сообщение ≤3500 знаков: событие → цепочка с пометкой отыгранности каждого звена →
  «моё звено» → обязательная строка **«потенциал X% × шанс Y% за Z недель ≈ матожидание»** →
  «кто продаёт нам и почему он неправ» → вердикт суда как аргументы за/против → счёт честности
  одной строкой;
- блокирующий линт подачи (≤4 числа, 0 тех.id, 0 эмодзи-мусора, тикеры только с именами) — не
  прошёл линт → пуш не уходит, алерт в дозор;
- «честный ноль»: если стоящего нет — одна строка «сегодня стоящего нет, вот почему», не простыня;
- из подачи убрать «Сила X/5» (серверный разбор 31.10: балл силы vs исход r=0.038 — шум) — вместо
  него честная база: «идеи этого трека сбывались в 48%» (= серверное предложение П-4);
- попутные однострочные фиксы корня ложной уверенности: `mathlib/cascade.py:209` (передать
  reliability/amplitude_sd в node_probability) + `portfolio.py:174` (месячный риск), оба с тестами.
**Гейт:** 5 боевых дней подряд ровно одно утреннее сообщение через линт; владелец письменно
подтверждает «формат тот». **Владелец видит:** вместо простыни — идею дня как прототип Cheniere/LNG.

### V1. Машина процесса — параллельно V0, нарочно крошечная (~2 сессии)
- `ops/roadmap_state.yaml` — единственный источник правды «какой этап, какой шаг, что блокирует»
  (создан 31.10, уже в репо);
- каждая рабочая сессия начинает с чтения state и заканчивает пушем + обновлением state;
- счётчик буксовки: шаг не двигается 2 цикла → автоэскалация владельцу одним вопросом-развилкой;
- вечерний чекпоинт-крон уже создан сервером 31.10 (`ops/checkpoint.sh`, 22:00) — добавить в дозор
  алерт «пуш в GitHub старше 4 дней»;
- еженедельный «машинист»: облачная Claude-сессия по расписанию (создана 31.10, пятницы) — читает
  state, прогоняет гейт текущего этапа, двигает очередь, шлёт пятничный отчёт человеческим языком.
**Гейт:** два автоцикла подряд «прочитал state → сделал шаг → запушил»; тест: искусственная буксовка
рождает вопрос владельцу. **Владелец видит:** строку в пятничном отчёте «конвейер жив: этап X, шаг
Y, не буксует».

### V2. Кнопки и петля владельца — недели 2–3 (~2 сессии)

### V3. Режим «качаем 2 дня» — центральная просьба 31.10, недели 3–4 (~3 сессии)
Кнопка [Качаем] → `journal/deep_dive.jsonl` → два утра подряд, из существующих блоков:
- **день 1 — устойчивость:** challenge.py (стресс котировками) + debate.py (адвокат/критик/слепой
  судья П10) + «что должно случиться, чтобы идея умерла» + замер перегретости (attention.py:

Направления прокачки система называет сама (владелец просил именно это).
**Гейт:** ≥1 идея прошла цикл вживую: кнопка → 2 углубления → паспорт; расходы в costs.jsonl под

### V4. Живые проценты: рекалибровка вместо константы — Подпись-2 (~2 сессии)
П-1 честно убил ложный уровень, но сделал все официальные вероятности константой (сейчас 46.7%).
Заменить на монотонную рекалибровку probability_raw по собственным форвард-исходам (изотоническая,
кластерный бутстрэп по дням/темам; интервал и N печатаются рядом). Честная рамка: измеритель и

возвращает идеям РАЗЛИЧИМОСТЬ подачи, а право говорить «мы отличаем» заработают только форвард-
исходы V5/V6.
**Гейт:** walk-forward: спред official-вероятностей ≥20 п.п., бины монотонны, skill не хуже
текущего; Подпись-2 получена. **Владелец видит:** идеи снова различимы («эта — 35%, та — 60%»),
внизу — живой счёт.

### V5. «Шансы недели» + голос мудрого экономиста: событийный трек 3–13 недель — Подпись-3 (~4 сессии)
Пятничный пуш: калиброванные проценты на громкие события мира («нефть выше $95 к Новому году —
12%») — зона, где умение доказано и наукой (Тетлок, рынки предсказаний), и собственной калибровкой.
Вопросы — по §9-стандарту с машинным критерием разрешения по ценам/данным; свой трек, свой счёт,
к деньгам не приближается.

**Голос мудрого экономиста (дополнение владельца 31.10, вечер):** новый агент-генератор тезисного
уровня — фундаментальная логика потоков («где убудет — где прибудет; дефицит → цена»), геополитика
и теория игр: контроль потоков сложно-воспроизводимых активов (энергия, вычисления, таланты,
критические материалы, военные технологии), сдерживание Китая и бенефициары-замещающие. Стартовый
реестр тезисов — **knowledge/theses_owner.yaml** (два тезиса владельца записаны 31.10). Механика:
тезис → наблюдаемые следствия → вопросы «Шансов недели» (запечатываются) → цепочки-кандидаты в V6.
Каждый тезис копит собственный форвард-счёт, и идея из тезиса показывает его владельцу («этот
взгляд пока сбывался в X%») — так «голос Баффета» получает право голоса, а не веру на слово.
Собирается из существующего: fundamental_school + game_theory_school (промпты в agents/prompts)
+ новый промпт экономиста потоков; его продукция идёт через те же печати и суд-аргументатор.
**Гейт:** 2 недели боевого крона, ≥16 запечатанных вопросов, пуш ушёл ≥2 раза через линт;
Подпись-3. **Владелец видит:** система впервые говорит о «всём мире», как он просил.

## 3. Самодвижение (чтобы «брошено» стало физически невозможным)

Четыре контура, три уже имеют несущие конструкции:
1. **Суточный (сервер, без человека):** фетч 06:45 → прогон 09:00 → «Идея дня» через блокирующий
   линт → кнопки пишутся ботом в журнал решений → дозор 21:15 алертит засухи и буксовки →
   вечерний чекпоинт 22:00 пушит журналы в GitHub (крон создан 31.10).
2. **Машинное состояние:** `ops/roadmap_state.yaml` — какой этап, какой шаг, что блокирует;
   правило «одна сессия = один этап»; гейт этапа обязан содержать ссылку на Telegram-пуш.
3. **Еженедельный машинист (облако):** назначенная задача по пятницам (создана 31.10) запускает
   свежую Claude-сессию: читает state и notices → делает следующий шаг → прогоняет гейт →
   пушит в master → обновляет state → шлёт владельцу пятничный отчёт: 3 строки человеческим языком
   + максимум один вопрос-развилка.
4. **Стоп-правила:** шаг буксует 2 цикла → вопрос владельцу; пуш в GitHub старше 4 дней → алерт;
   точки Б1/Б — публичный экзамен с заранее записанными критериями.

Усилия владельца по дизайну: ~3 клика в неделю + 1 развилка в месяц. Всё остальное едет само.

## 4. Килл-лист (меньше, но живое)

- **Дайджест-простыня** (13.8К знаков, ~30 чисел, «ранг показа 0.2042») — убить в V0.
- **«Разбор дня» как главный пуш** — демотировать: постмортемы по запросу и по пятницам, код
  переиспользуется внутри «Идеи дня».
- **Мегамозг/funnel как прогнозный мотор** — заморозить, НЕ возвращать: уже был в бою 15–19.06
  и дал 0 через те же ворота. Состязательный аппарат (challenge/debate) живёт в V3 — это и есть
  «мегамозг» в полезной форме: не предсказывает, а пытает идею.
- **Волны Эллиота** — из активных школ в архив (нефальсифицируемы); теханализ — только
  momentum/волатильность как детерминированные фильтры; теория игр — рамка «кто продаёт нам»,
  уже инвариант.
- **5-дневный горизонт как дефолт ставки** — заменить на 3–13 недель (V5/V6).
- **Служебный шум** (бюджет-строка, дозор на жаргоне) — в одну человеческую фразу и в пятничный отчёт.

## 7. Главные риски и как они закрыты

1. **Идеи без edge будут промахиваться, и честное табло это покажет.** Обещание переформулировано
   ДО старта: research-партнёр со счётом, не «обгоним рынок»; экономика печатается вплоть до
   «матожидание скромное — идея для изучения»; пустой день — норма; Б1 через 4 недели даёт раннюю
   развилку.
2. **«Перекраска трупа»** (красивый формат поверх пустого потока). Закрыто парой V0+V6: подача
   чинится сразу, источник edge строится параллельно, и точка Б меряет ОБА.
3. **Процесс съест бюджет.** Машинист — 1 сессия/нед; LLM-потолки прежние ($500/мес, факт ~$12);
   затраты пишутся в costs.jsonl, видны в /budget.
4. **Снова брошено.** Теперь брошенный этап физически шумит: буксовка → вопрос; тишина в GitHub →
   алерт; пятница без отчёта — сама по себе сигнал.

## Поправка 31.10 (вечер-2): вердикт панели первых принципов

По вопросу владельца «правильная ли архитектура или всё переделать» прогнана состязательная
панель: проектировщик с чистого листа (не глядя в код) + стилмен сноса + стилмен сохранения.
Схождение всех трёх:

1. **Фундамент верен, сносить нельзя**: измерительный слой (печати, хэш-цепи, слепой суд,
   форвард-история 3 567 исходов) — невозобновимый актив; полный снос обнуляет часы
   доказательства (П16 запрещает бэктест) и повторит ту же систему минус честность.

   корреляции (lag=0, undirected) + зона тикер×5дней» опровергнут собственным экспериментом
   на N=3567. Знание обязано НАКАПЛИВАТЬСЯ: библиотека механизмов (правило + теория + условия
   срабатывания + прецеденты с лагом/амплитудой + форвард-репутация), экономист = куратор
   библиотеки и дежурный-сопоставитель (ищет применимый механизм, а не сочиняет новый).
3. **Порядок этапов исправлен**: новое ядро V5∥V6 — главное содержание после V0/V2;
   V3 (прокачка) и V4 (рекалибровка) работают ПОВЕРХ потока нового ядра.
4. **Новая несущая стена в V6**: слой «что уже в цене» (фьючерсные кривые, опционные
   ожидания, консенсус) — без него строка «отыграно на W%» не имеет измерителя.
