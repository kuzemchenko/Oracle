## П-3. Ключи датчика «внимание»: Т4 расширяется с «3 мусорных ключа» до механизма (ТРЕБУЕТ ПОДПИСИ)

Факт: реестр `journal/attention_keys.jsonl` — 408 записей, 400 из них назначены как «слова новостного
кластера картографа»: `discusses`, `than`, `throne`, `slips`, `announces`, `sale`, `quarter`, `week`…
Ни один ключ реестра не фетчился с 15.07 (суточный фетч упирается в лимит Google после ~19 тематических
ключей; «фетч сейчас» — 0 успехов из ~900 попыток). Покрытие датчика 8,5% — и даже эти 8,5% измерены по
ключам, не имеющим отношения к идее.

Предлагаю (разовая журналируемая пересдача по правилам Т4, старые записи остаются в провенансе):
1. Источник «слова новостного кластера» — ИСКЛЮЧИТЬ из назначения ключей (кластерные слова → только в
   событие/протокол, не в датчик).
2. Ключ идее назначается ТОЛЬКО из курируемых: тема универсума (`trends_keywords`), сиды
   `config/attention_keys.yaml`, или ключ, прописанный в цепочке (`cascade_chain`). Нет курируемого ключа —
   честно «не измерено» (это уже и так 91,5% случаев, но станет правдивым «нет ключа», а не ложным «ждём фетча»).
3. Кэп суточного фетча `MAX_ATTENTION_FETCH_KEYS` 30 → 0 для реестра (фетчим только то, что влезает в лимит:
   темы + сиды ≈ 27 ключей). Когда курируемых ключей станет больше лимита — поднимать вопрос, не кэп.

## П-4. Балл «силы идеи» в подаче Топ-3 (ТРЕБУЕТ ПОДПИСИ — меняет, что владелец видит)

Факт: за 101 прогон 501 вердикт исследовательского суда сверен с исходом. Корреляция балла с исходом 0.038.
Балл < 2 → 43% попаданий, 2–2.5 → 51%, 2.5–3 → 47.5%. Судья ставит `mechanism_real ≤ 2` в 498/500,
`asymmetry ≤ 2` в 500/500: балл различает идеи только «неочевидностью» и «проверяемостью», не связанными
с исходом. Денежный суд: 116/116 РАЗБИТА, разбитые сбылись в 52.6% — как всё.

Предлагаю:
1. В подаче заменить «Сила 2.8/5» на честную базу: «Идеи этого трека за 3,5 месяца сбывались в 48% (n=1932)».
   Балл оставить внутри протокола (для будущей проверки), из заголовка убрать до тех пор, пока на ≥300
   исходах он не покажет разделение корзин с ДИ, не пересекающимися с базой.
2. Критерий `mechanism_real` — не трогать (он честно говорит, что механизмов нет); это не поломка судьи, это
   диагноз генератора идей.

B2 / Этап 4 / Этап 5 строятся поверх движка, где сигнал не измерен нигде. Предлагаю вместо них один
исследовательский этап: «Где сигнал» — систематический поиск подмножества среди 1932 провизорных исходов

попаданием статистически выше базы при поправке на множественность (FDR Бенджамини–Хохберга, как в §6).
