# Заявки охотника на день

Файл `<YYYY-MM-DD>.txt` — «день взят»: охотник коммитит его ПЕРВЫМ, до поиска.
Другой запуск того же дня (ранний 03:17 UTC / страховочный 10:17 UTC / ручной) охоту не повторяет,
если заявка моложе 4 часов или идея дня `idea_<дата>_*.push.txt` уже в master.
Бот эти файлы не читает (он смотрит только `reports/ideas/idea_*.push.txt`).
