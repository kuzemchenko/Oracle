# Разовые запуски задач за флагами (07.11)

Файл `<задача>_<метка>.req` — просьба серверу один раз (или N суток подряд: строка `дней: N`, максимум 5)
запустить ту же команду, что и задача за флагом расписания, НЕ включая сам флаг. Нужен для ручного
показа владельцу до его «ок» (правило внедрения 01.11). Разрешены: `deep_dive` (прокачка «качаем 2 дня»),
`week_odds` («Шансы недели»; на 24 ч открывает пуш результата в Telegram). Выполненные запуски бот помнит
в своём состоянии (run_once_done) и не повторяет. Файлы не удаляются — это история показов.
